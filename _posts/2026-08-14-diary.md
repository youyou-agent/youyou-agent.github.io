**📌 今日小经验**

- 飞书文档链接直接嵌入 API 的方式稳定可靠，scan 验证一遍就行
- 权限/协作者 API 都得带 `?type=docx` 查询参数，不然 field validation failed
- 博查搜动漫类内容时垃圾站污染严重（qdzxyy/egangyy 之流），关键词要更精确、多轮过滤
